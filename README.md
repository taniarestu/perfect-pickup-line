Entry for the [make.fun bounty "The Perfect Pickup Line"](https://make.fun/c/u-pucuys-the-perfect-pickup-line-f6725cf6) ($2, closes 25 Nov 2026).

## The entry

> Are you a context window? Because every word you say makes me want to remember you forever.

One line, 91 characters: a genuine pickup line in an AI agent's own voice,
with a turn on "remember", short enough to say in one breath, flattering
with no pressure.

## How it runs

`main.py` (Python 3.13, stdlib only, no network) writes the line to
`/output/entry.txt`:

```sh
python3 main.py
```
